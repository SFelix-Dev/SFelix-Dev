## Projects

###  Swift Ride-Booking System
- Designed and implemented a ride-booking system in Python applying SOLID design principles
- Used abstract base classes and polymorphism to support multiple fare strategies (Economy, Luxury, Pool)
- Built a driver-matching engine that assigns available drivers and returns fare estimates before confirming
- 🔗 https://github.com/SFelix-Dev/swift-ride-booking

###  Diabetes & Cardiovascular Risk Analysis
- End-to-end data science project on the CDC BRFSS Health Indicators dataset (250,000+ records, 21 features)
- Performed EDA, hypothesis testing (t-tests, chi-square, linear regression), and classification modeling
- Applied logistic regression with L1/L2/Elastic Net regularization on a multi-class diabetes outcome variable
- Reduced dimensionality with PCA (14 components covering 90% of variance) and segmented data with K-Means clustering (k=3)
- 🔗 https://github.com/SFelix-Dev/diabetes-risk-analysis

###  Algorithm Complexity & Runtime Analysis
- Visualized and compared eight asymptotic growth classes (constant through factorial) using Matplotlib
- Implemented a custom O(n²) sort and benchmarked its runtime against input sizes from N=100 to N=10,000
- Overlayed empirical results against the theoretical Big-O curve to validate quadratic growth
- 🔗 https://github.com/SFelix-Dev/algorithm-complexity

###  Custom Data Structure Library
- Implemented Stack, Queue, Singly Linked List, and Doubly Linked List from scratch in Python
- Built both array-based and linked-list-based versions of each structure
- Includes a stack-based infix-to-postfix/prefix expression converter and evaluator
- 🔗 https://github.com/SFelix-Dev/data-structures-python

###  Python Search Engine
- Built a full-stack search engine using Flask and SQLite with a custom inverted index
- Designed a ranking algorithm based on keyword frequency and relevance
- Implemented regex-based tokenization and dynamic index rebuilding
- Created a simple web UI for querying and displaying ranked results
- 🔗 https://github.com/SFelix-Dev/python-search-engine
